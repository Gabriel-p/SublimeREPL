Welcome to SublimeREPL
======================

This fork of SublimeREPL is focused on the ProjectVenvRepl Python workflow.

Included functionality:
 - interactive Python REPL sessions
 - running the current Python file through ProjectVenvReplCommand
 - the core subprocess-backed REPL view, restart, and history navigation support

Removed functionality:
 - config-driven Python/IPython/virtualenv launchers
 - text transfer, autocomplete, build-system hacks, and other unused helpers
