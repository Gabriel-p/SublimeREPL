Welcome to SublimeREPL
======================

This fork of SublimeREPL is focused on Linux-only Python workflows.

Included functionality:
 - interactive Python REPL sessions
 - running the current Python file
 - launching PDB for the current Python file
 - IPython integration through config/Python/ipy_repl.py
 - local virtualenv discovery via python_virtualenv_paths
 - REPL history, restart, and text transfer support

Removed functionality:
 - non-Python language integrations and their menu/command registrations
 - non-Python helper scripts and custom REPL classes
